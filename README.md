# 📧 Automated Outreach Pipeline Simulator

A Python-based simulation of a full-stack automated outreach system that mimics real-world sales intelligence and email automation workflows.

---

## 🚀 Overview

This project simulates an AI-driven outreach pipeline that:

- Discovers similar companies based on a domain
- Generates decision-maker contacts
- Creates professional email addresses
- Builds personalized outreach emails
- Simulates sending email campaigns
- Logs campaign reports locally

> ⚠️ Note: This project is a **simulation only**. No real emails are sent.

---

## 🧠 Key Features

- End-to-end pipeline automation
- Modular service-based architecture
- Randomized but structured data generation
- Email campaign preview system
- Campaign logging system
- Streamlit web dashboard interface
